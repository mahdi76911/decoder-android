# Decoder (MyApplication)

A small Android **file decoder** utility written in Java. It decodes large
files on background threads so the UI never blocks, and uses the modern
**Storage Access Framework (SAF)** to read and write files.

## Features
- Large-file decoding off the main thread (`SaveFileTask` / `SaveBigFileTask`)
- Progress feedback while a big file is processed
- SAF-based file picking and saving (`androidx.documentfile`)
- Runtime permission handling

## Tech
- **Language:** Java
- **Concurrency:** background worker tasks + `android.os`
- **Files:** `java.io` + `androidx.documentfile` (SAF)
- **SDK:** compile/target 29, min 18

## Project layout
```
app/src/main/java/com/example/myapplication/
    MainActivity.java       # UI + SAF wiring
    SaveFileTask.java       # standard-size file decode
    SaveBigFileTask.java    # large-file decode (chunked)
```
## Building

These projects predate modern toolchains, so they need an older JDK:

- **JDK 8 or 11** — set `JAVA_HOME` accordingly (JDK 17/19 will fail the Gradle 5.x daemon).
- **Gradle 5.1.1** (via the bundled `./gradlew`) and **Android Gradle Plugin 3.4.2**.
- Point `local.properties` at your SDK (auto-generated by Android Studio):
  ```
  sdk.dir=C:\\Users\\<you>\\AppData\\Local\\Android\\Sdk
  ```
- Open in Android Studio (Hedgehog or older is safest) and build, or:
  ```
  .\gradlew assembleDebug
  ```
